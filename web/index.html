Gravity 980 Smoker Bridge

Version {{VERSION}} · ESP32-S3 (16 MB flash, 8 MB PSRAM) · Home Assistant

Connects to the Char-Griller Gravity 980's stock controller over Wi-Fi or Bluetooth and adds learning cook-time predictions, stall detection, cook programs, alerts and a Bluetooth proxy for wireless thermometers.

Install

Your browser can't flash boards. Open this page in Chrome or Edge on a computer. This page must be opened over HTTPS.
  • Plug the ESP32-S3 into this computer with a USB-C data cable. If the board has two USB-C ports, use the chip's own port, labelled USB or OTG (not COM/UART): the Wi-Fi step after flashing only works there.
  • IPEX-antenna boards: click the antenna on before powering the board.
  • After flashing, enter your Wi-Fi details when asked. If you aren't asked, join the Smoker setup Wi-Fi hotspot from your phone and pick your network there.

Board not detected? Hold BOOT, tap RST, release BOOT, then try again.

Then, in Home Assistant

  1. Add the device: a Discovered notification appears for “Smoker”. Click Add.
  2. On the device page, set Grill IP address to your grill's address (give it a DHCP reservation). Bluetooth works without it.
  3. Leave Allow the device to perform Home Assistant actions off: notifications and cook summaries reach Home Assistant as events, which don't need it.
  4. Add homeassistant/packages/smoker.yaml and the Smoker dashboard integration (HACS custom repository) — see the install guide.

Firmware updates appear in Home Assistant as an update on the device. Release notes · Source and docs. Unofficial hobby project, not affiliated with Char-Griller.
